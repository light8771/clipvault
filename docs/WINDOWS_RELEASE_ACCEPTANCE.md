# Windows 首次发行验收（待执行）

本表是补齐发行阻断项的操作清单，**所有项目当前均未被这份文档判定通过**。本机隔离 Web 预览、Go 测试和旧交接记录不替代干净系统验收。

## 环境与隔离

准备新的 Windows 10 x64 和 Windows 11 x64 虚拟机快照；不使用已有个人数据库、剪贴板、邮件账号或商业订单私钥。记录 Windows build、候选版本、Go/GCC、EXE SHA-256/签名、视口和每项实际结果。验证时关闭网络共享/云盘同步，只使用虚构样本。

完整开发启动要显式设置新的 `CLIPVAULT_DATA_DIR`。为避免默认控制文件/日志接触个人环境，应在全新 VM 用户中运行；不要在本机正式实例仍运行时尝试第二个托盘实例。`dev-run.ps1` 会写入开发授权凭据，只能用测试私钥；生产签发机/密钥不得进入 VM。

未注入公钥的空构建与开发公钥构建是不同状态：先验证 unconfigured 的录制/备份门禁，再用 VM 内生成的开发密钥/测试激活完成全功能验证。记录真实行为，不靠截图文字推断录制已经启动。
