# ClipVault 许可证、署名与公开范围

2026-10-21，维护者授权由 Codex 选择许可证、版权署名及商业公开范围；本次确定如下，**不是再次等待许可证选择**。公开上传仍需单独批准。

## 已采用的方案

- **Apache License 2.0**：根目录 LICENSE 保存 Apache 官方完整原文；NOTICE 记录项目署名与第三方声明入口。
- **版权署名：Copyright 2026 ClipVault contributors**。采用项目贡献者集体署名，各贡献者保留对应贡献的权利；不转让版权，不代第三方授权，也不推定存在某个公司主体。
- **公开全部有权许可的自有源码与文档**，包括客户端、离线激活/验签、签发工具、构建脚本与测试，以及保留历史中的相应项目原创版本。第三方代码和声明沿用其原许可证；私人数据与签发凭据不属于计划发布内容。
- **保留现有商业激活实现**，不删除录制/备份门禁、不增加绕过开关。官方可提供收费构建、签发、分发和支持服务；Apache-2.0 接受者同时有权修改代码（包括授权检查）、自行构建及商业再分发，不能附加必须购买官方激活的源码使用限制。

选 Apache-2.0 的理由是明确的专利许可及相关终止条款，适合允许商业参与和社区修改的范围。分发应保留 LICENSE、适用 NOTICE 和第三方声明，修改文件须按许可要求标明。商标权不因代码许可自动授予。
