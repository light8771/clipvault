# 图片识别连接

入口：**设置 → 图片识别**。进入页面并完成必要验证后自动读取连接配置，可直接新建或编辑，先点“测试连接”，确认后再保存。测试使用当前表单参数，不要求先保存或填写连接名称，也不会修改已保存连接。“读取当前配置”用于手动刷新或加载失败后重试。测试使用内置的 `ClipVault OCR TEST / 12345 ABC xyz` 图片，不读取剪贴板，不写入历史记录。

图片识别拥有独立菜单和页面 `/settings/ocr`，也可从设置首页卡片、设置搜索或识别弹窗进入。“网络与服务”只保留监听地址和时区设置。

菜单、表单、确认提示、状态、错误和图片名称统一使用应用多语言词条，内置简体中文与英文，也遵循自定义语言的回退规则。用户填写的连接名称、模型名、提示词和识别原文不会随界面语言自动改写。切换语言不会修改连接或识别缓存。

支持最多 16 个独立连接，可选择默认连接。点击历史图片卡片的“识别文字”后，弹窗立即使用默认连接识别，无需再次点击。单张图片不显示选择框，多图记录保留切换入口并在切换后识别。需要更换连接时到设置页修改默认连接。

识别结果自动保存，弹窗底部固定显示保存状态。修改文字后显示“有修改未保存”，点击“保存修改”提交；改回已保存内容会清除未保存标记。有修改时复制按钮显示“保存并复制”，保存失败不会继续复制。“对照原始识别”在编辑区旁展开只读原文，窄屏上下排列，修订不会覆盖原始识别内容。

## 自动识别新图片

在本页底部开启“自动识别新采集的图片”，点击“保存自动识别设置”生效。默认关闭，使用已保存的默认连接；未保存的连接草稿不能用于开启自动识别。百炼必须有可解密的 Key，云端必须另行勾选自动上传授权。建议先用“测试连接”确认服务可用。

仅处理开启后由录制器成功保存的截图与内嵌图片，跳过敏感记录和仅引用文件路径的图片。不扫描旧历史、导入或恢复的数据，不自动覆盖系统剪贴板。识别结果自动存入原记录并参加搜索，可在历史页查看、编辑、复制或手动重试。

后台单任务执行，最多排队 32 条记录，每条最多识别 8 张图片；超出的部分留待手动识别。复用缓存，与手动任务互斥，失败不自动重试、不切换连接，原图及已有修订保留。关闭开关会取消自动请求并丢弃队列；已经发送到服务端的图片无法撤回。

变更默认连接、密钥或识别参数后自动识别暂停，必须重新保存开关设置，云端再次确认授权；即使切回旧参数也不会自行恢复。应用重启保留已保存的开关，但不会补跑旧队列。自动策略是本机设置，不随记录导出或备份，本次新增设置不改变数据库或导出版本，无需重置数据库。

## 支持的协议

| 协议 | 运行位置 | 接口根地址示例 | 默认请求路径 | 需自行准备 |
| --- | --- | --- | --- | --- |
| 阿里云百炼 | 云端 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `/chat/completions` | 同地域/业务空间的 Key、具备图片能力的模型权限 |
| 通用视觉接口 | 云端或本机 | 服务商提供的 HTTPS 根地址，或本机服务的 `/v1` 地址 | `/chat/completions` | 接口支持 Chat Completions 图片输入，响应为单个文本 choice |
| Ollama | 本机 | `http://127.0.0.1:11434` | `/api/chat` | 启动 Ollama，并下载支持图片的视觉模型 |
| Umi-OCR | 本机 | `http://127.0.0.1:1224` | `/api/ocr` | 启动 Umi-OCR，开启 HTTP 服务 |

根地址和请求路径会直接拼接，例如 `http://127.0.0.1:1234/v1` + `/chat/completions`。通用协议可以连接启用相应接口的 LM Studio 等服务；服务商名称不代表全部模型或端点均兼容。

本机只允许 `localhost` 或回环 IP，不使用系统代理，不跟随重定向。这里的“本机”是运行 ClipVault 后端的电脑，不是访问网页的另一台设备。ClipVault 只向所选本机服务发送图片；该第三方软件是否继续联网由它自身决定。

云端只允许 HTTPS。点击列表“识别文字”即按默认连接发起识别，弹窗显示连接名称、目标及上传/费用提示；请求携带加载时的配置指纹，配置变化会拒绝请求。设置页测试云端仍单独提示费用。不会自动将本机失败请求转发到云端。

## 高级参数与接口变化

可配置请求路径、提示词、10–600 秒超时、256–32768 的输出上限、Chat Completions 的 `max_tokens` / `max_completion_tokens` 字段，以及附加 JSON 参数。

附加参数最多 32 项、8192 字节。可用于协议允许的生成参数，例如通用接口的 `{"temperature":0}`，或支持该选项的 Ollama 模型的 `{"think":false}`。不能覆盖模型、消息、图片、鉴权、流式开关或加入工具调用。

Umi-OCR 不使用提示词和视觉模型名，输出固定请求纯文本。附加参数只允许 `ocr.language`、`ocr.cls`、`ocr.limit_side_len`、`tbpu.parser`；语言值由所安装的 OCR 引擎决定，不应照搬其他安装的模型路径。Umi-OCR 请求在 ClipVault 内串行执行，忙碌时提示稍后重试。

这是一层**协议适配器与连接配置**：地址、模型、路径和生成参数变化通常可以直接调整配置；认证方式、请求结构或响应结构变化仍需修改对应适配器。不会猜测陌生响应、静默切换协议或执行自定义脚本。HTTP 适配只使用 Go 标准库，没有新增 Go 包依赖。

## 密钥、缓存和现有数据

每个连接独立使用 Windows DPAPI 保存密钥，接口不返回密钥。更换协议、位置、根地址或路径时，已有密钥必须重新填写或明确清除。无鉴权本机服务可不填 Key。记录导出和备份不包含连接配置及密钥。

缓存按图片、连接 ID、协议配置、提示词和适配/预处理版本隔离。重新识别跳过缓存，旧成功结果和用户修订在失败时保留。当前模型原文与用户修订分别保存，搜索优先使用修订内容。

本次多连接扩展没有改变 schema v14、JSON/加密导出 v11、XLSX v10，不需要重建历史数据库。早期单百炼连接配置会明确报不兼容；使用“重建连接配置”只清除识别连接及其密钥，再重新填写。它不清除历史记录或识别结果。

## 当前验收边界

本轮验证使用虚构图片、本机协议桩和隔离数据库，不能据此保证某个真实模型的准确率。请在自己的连接中用“测试连接”确认服务、鉴权与模型，再用中文聊天、代码和表格样例评估效果。Windows 原生 OCR、本地软件进程自动启动和长图切片尚未实现。
