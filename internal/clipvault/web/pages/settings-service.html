公网访问

本服务定位为本机 / 局域网数据 API，不提供内置 HTTPS。如需公网访问，请自行使用 Caddy、Nginx 等反向代理映射（自行负责证书与 TLS 配置），并保持监听地址为回环地址。

局域网访问风险 非回环地址会通过明文 HTTP 暴露剪贴板服务。保存前必须设置锁屏密码；建议仅在可信网络中使用，并检查 Windows 防火墙规则。
