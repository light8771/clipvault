MCP 端点

Streamable HTTP 端点，填入 MCP 客户端的 URL 配置即可

关闭后监听端口立即释放；MCP 失败或过载不影响剪贴板录制与主界面

监听范围

仅本机只允许 127.0.0.1；局域网监听 0.0.0.0；指定地址可绑定到具体网卡 IP

本机网卡 IP，例如 192.168.1.10

端口范围 1024–65535，默认 17840；不能与 Web 界面或数据接口端口相同

明文 HTTP 提示 MCP 使用 HTTP，建议仅在可信本机或局域网中使用，请勿直接暴露到公网。持有有效 Token 的客户端可以读取其权限范围内的 ClipVault 数据。

客户端接入示例

把 URL 换成上方端点、Token 换成下方生成的 MCP 令牌

MCP 客户端配置 
{
  "mcpServers": {
    "clipvault": {
      "url": "{MCP_URL}",
      "headers": {
        "Authorization": "Bearer cv_你的MCP令牌"
      }
    }
  }
}
工具调用速览（易错点） 
// ① id / ids 是十进制字符串，不要传数字（传整数会被校验拒绝：want "string"）
get_clipboard_item    { "id": "42" }
get_clipboard_items   { "ids": ["1", "2", "42"] }          // 最多 100 个，顺序保持

// ② kind 是字符串数组；sourceApp / groupId 是单个字符串（两者类型不同）
search_clipboard      { "kind": ["image", "text"], "sourceApp": "chrome.exe", "groupId": "7" }

// ③ 可选过滤：query / from / to（RFC3339）/ starred / sensitive / limit（默认 50，最大 500）
search_clipboard      { "query": "docker", "from": "2026-08-01T00:00:00+08:00", "limit": 20 }

// ④ 错误约定：业务失败以 isError=true + 文本消息返回（如 "not found"、
//    "invalid request: ..."），不是 JSON-RPC error；参数校验失败同理。
//    工具与输入 Schema 可通过 tools/list 获取，其中含各参数类型与枚举值。

访问令牌

MCP 令牌只能调用 MCP 服务；数据接口令牌在这里不可用。Token 只在创建时完整显示一次，请立即复制保存

用于标识使用方，例如「Codex」「Claude Desktop」

到期后 Token 自动失效；推荐 30 天或 90 天

敏感数据授权

新令牌默认只能读取普通数据；创建后可在令牌列表中单独开启敏感授权。开启时敏感记录对此令牌可见，关闭时完全不可见（与不存在无异）
