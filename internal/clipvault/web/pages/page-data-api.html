数据接口文档

快速开始

  1. 在上方「服务设置」中启用数据接口，记下访问地址（本文档示例已按当前地址 {BASE_URL} 生成）
  2. 在「访问令牌」中生成一个 Token（只显示一次，立即保存）
  3. 把 Token 放进 Authorization: Bearer 请求头，POST 到 /api/v1/query 即可查询
curl 
curl {BASE_URL}/api/v1/query \
  -H "Authorization: Bearer cv_你的Token" \
  -H "Content-Type: application/json" \
  -d '{"resource":"clipboardItems","filter":{"text":{"contains":"docker"}},"limit":5}'
PowerShell 
Invoke-RestMethod -Uri {BASE_URL}/api/v1/query -Method Post `
  -Headers @{ Authorization = 'Bearer cv_你的Token' } `
  -ContentType 'application/json' `
  -Body '{"resource":"clipboardItems","limit":5}'
Python 
import requests

r = requests.post(
    "{BASE_URL}/api/v1/query",
    headers={"Authorization": "Bearer cv_你的Token"},
    json={"resource": "clipboardItems",
          "filter": {"text": {"contains": "docker"}},
          "limit": 5},
    timeout=10,
)
print(r.json())

认证

除健康检查外，所有请求必须在请求头携带 Authorization: Bearer <Token>。Token 只认请求头，不支持 URL 参数传递。Token 过期、被撤销或不符都会返回 401，见下方错误码表。

端点

最后一列是「访问记录」里显示的审计操作名，可用于把调用记录对应回本表端点。

GET/api/v1/health健康检查，无需 Token；返回服务与激活状态不记录
GET/api/v1/metadata资源字段、可筛选/可排序字段与限制的机器可读描述审计 get_metadata
POST/api/v1/query核心查询：筛选、排序、分页、分组统计审计 query_items
GET/api/v1/items/{id}单条完整记录（文本不截断）审计 get_item
POST/api/v1/items/batch-get按 ID 批量取完整记录，最多 100 个审计 batch_get
GET/api/v1/items/{id}/content二进制内容：托管图片为 PNG，文本为纯文本审计 get_content

查询接口 POST /api/v1/query

请求体是一个 JSON 对象，所有字段均可省略。示例把「最近 24 小时内、来自 Code.exe、内容包含 docker 的非敏感文本」按时间倒序取 50 条：

请求体 
{
  "resource": "clipboardItems",
  "filter": {
    "createdAt": { "gte": "2026-08-18T00:00:00+08:00" },
    "kind": { "in": ["text"] },
    "sourceApp": { "eq": "Code.exe" },
    "text": { "contains": "docker" },
    "sensitive": { "eq": false }
  },
  "orderBy": [{ "field": "createdAt", "direction": "desc" }],
  "limit": 50,
  "cursor": null
}
resource固定为 "clipboardItems"
filter字段 → 操作符 → 值 的嵌套对象，多个字段之间为 AND 关系
orderBy最多一条：createdAt 或 id，方向 asc/desc；默认 createdAt desc
limit每页条数，默认 50、最大 500
cursor翻页游标：把上一页响应的 nextCursor 原样传入
groupBy + aggregate分组统计（互斥于 cursor）：{"groupBy": ["sourceApp"], "aggregate": {"count": "*"}}，返回各组数量
响应 
{
  "items": [
    {
      "id": "42",
      "createdAt": "2026-08-19T02:23:45Z",
      "kind": "text",
      "text": "docker compose up -d",
      "textTruncated": false,
      "byteLen": 19,
      "sha256": "9f2b…",
      "sourceApp": "Code.exe",
      "sourceWindow": "main.go — clipvault",
      "starred": false,
      "sensitive": false,
      "groupId": null,
      "contentAvailable": true
    }
  ],
  "nextCursor": null,
  "hasMore": false
}

列表里的 text 超过 4000 字符会截断并标记 textTruncated: true；要完整内容用 GET /api/v1/items/{id}。hasMore 为 true 时，把 nextCursor 传入下一次请求继续翻页。

筛选字段与操作符

createdAtgte gt lte lt，值为 RFC3339 时间字符串（如 2026-08-19T00:00:00+08:00）
kindeq neq in；取值：text / image / files / office / archive / video
ideq neq in gt gte lt lte，值为整数或整数数组
sourceApp / sourceWindoweq neq in contains startsWith endsWith（不区分大小写）
textcontains eq neq（contains 不区分大小写）
starred / sensitiveeq neq，值为布尔
groupIdeq neq in，值为分组 ID

白名单之外的字段或操作符一律返回 400 unsupported_filter，不会执行任何拼接表达式。

错误处理

所有错误统一为 {"error": "错误码", "message": "人类可读说明"}，按 HTTP 状态码区分：

400invalid_request 请求体不合法 / unsupported_filter 不支持的字段或操作符 / invalid_cursor 游标损坏
401missing_token 未带请求头 / invalid_token Token 错误 / token_expired 已过期 / token_revoked 已撤销
403activation_required 授权未激活
404not_found 记录不存在或无内容
413response_too_large 内容超过大小上限
429too_many_requests 触发限流（10 次/秒，可看 Retry-After 头）/ api_busy 并发已满
500 / 504internal_error 内部错误 / query_timeout 查询超时（5 秒）

限制速览：每页最多 500 条；批量取最多 100 条；单次查询 5 秒超时；每个 IP 每秒 10 次请求（突发 30）；并发查询最多 4 个。所有访问都记录在「访问记录」中，包括请求摘要与完整请求体（便于审计谁查了什么），但不包含剪贴板正文与 Token 原文。
